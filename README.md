# Brinky Fiesta 2.0 Android

Proyecto Android nativo que contiene la versión estable de Brinky Fiesta dentro de una WebView local.

## Características
- No depende de Chrome para abrir.
- Funciona en modo horizontal y pantalla completa.
- El juego y sus recursos están integrados en la aplicación.
- Conserva audio, controles grandes, récord y pausa/continuar.
- Detiene audio y temporizadores al bloquear o minimizar el teléfono.

## Abrir en Android Studio
1. Abre Android Studio.
2. Selecciona **Open**.
3. Elige la carpeta `BRINKY_FIESTA_2_0_ANDROID`.
4. Permite que Android Studio descargue/sincronice Gradle y Android SDK 35 si lo solicita.
5. Conecta tu teléfono con depuración USB o inicia un emulador.
6. Pulsa **Run ▶**.

## Crear APK
En Android Studio: **Build > Build Bundle(s) / APK(s) > Build APK(s)**.

## Crear AAB para Google Play
En Android Studio: **Build > Generate Signed Bundle / APK > Android App Bundle**.
